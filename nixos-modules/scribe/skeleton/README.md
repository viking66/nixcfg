## How this works

- Each screenplay lives under `screenplays/<slug>/`.
- Screenplays are written in [Fountain](https://fountain.io/) markup
  (`screenplay.fountain`); PDFs are auto-generated by a pre-commit hook.
- Every named character has a wiki page at
  `screenplays/<slug>/characters/<Name>.md` with backstory, voice, and arc.
- Research notes go at `screenplays/<slug>/research/<topic>.md`.

See `CLAUDE.md` for the full working contract.
